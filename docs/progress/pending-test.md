# 待测试

## 统一账号与门户（P2，已在本地端到端验证，待测试环境复验）

- 注册后自动登录；用户名登录；new-api 开启邮箱验证后邮箱登录
- 兑换码充值后余额在页面、右上角、左下角同步刷新
- 余额开通会员：确认框、到期日、new-api 分组升级为会员分组、会员额度（订阅额度为 0 时显示"不限额度"，属误配）
- 预估积分：固定价模型显示积分并随会员折扣变化；按量模型无法预估时不显示价格（不再显示"按量计费"）
- 实际生成扣费与预估一致（会员先扣赠送额度，用完扣钱包）
- 新注册 SSO 用户默认使用平台渠道（不能落到本地直连）
- 旧访问令牌（P2 前签发、无钱包权限）访问账户接口时提示重新登录
- 运营横幅倒计时到期自动隐藏；链接仅允许 https 或站内路径
- 画布编辑器、登录页、SSO 回调页不显示导航侧栏；手机宽度使用抽屉导航
- Turnstile 开启/关闭两种情况下的登录、注册、发送验证码
- `DATA_ENCRYPTION_KEY` 缺失时 SSO 模式拒绝启动；数据库中凭据为 `enc:v1:` 密文

## 生成任务队列与我的作品（P3-A）

- `LOCAL_STORAGE_DIR` 设置后未配置 S3/WebDAV 也能上传图片与保存作品；配置 S3 后新文件写 S3、旧本地文件仍可读
- SSO 模式图片工作台生成：任务 ID 以 `genjob-` 开头，结果出现在"我的作品"，刷新页面后进度继续
- 失败分类：参数错误/内容审核拒绝一次失败；上游 5xx、429、连接失败退避重试，最多 3 次；请求发出后的超时与图片接口 504/524 不重试，避免重复扣费
- 生成中重启后端：约 2 分钟后任务被回收并重新执行
- 每用户并发上限（普通 2、会员 4）与全站上限生效；单用户排队中任务最多 100 个
- 我的作品：类型标签、状态数量、加载更多、单张/批量下载（多张为 zip）、批量删除、重试、取消、剩余天数提示
- 到期作品每小时清理，存储文件同时删除
- `/api/files/:id/content` 对非图片/音视频类型强制下载，并带 nosniff 与 CSP sandbox
- 三库（SQLite、MySQL 5.7、PostgreSQL 9.6/17）领取并发测试通过

## 模型选择接入 new-api 分组

- 新注册统一账号用户首次进入：配置弹窗与画布节点已有默认生图/文本模型（来自 new-api SSO 客户端 `defaults`），无需设置即可生成
- 模型下拉框：左栏“平台渠道”列出可用分组与倍率徽章（<1 绿、=1 灰、>1 橙），“我的渠道”列出自定义渠道并可“添加渠道”；右栏按类型、厂商、搜索过滤，按次计费显示“≈x 积分/次”与原价，按量显示“按量 · ×倍率”，默认模型带“默认”标签；画布窄节点内弹层保持两栏
- 选择非账户分组（如 vip）生成后，new-api 消费日志的分组为该分组、令牌名为 `sso:infinite@vip`；同一分组重复使用不再新建令牌
- 在 new-api 删除 `sso:infinite@<分组>` 令牌后再次生成：自动重新获取并成功；禁用（非删除）时提示去 new-api 启用
- 自定义渠道与平台渠道切换：自定义渠道请求不经 new-api 计费、不进生成任务队列
- new-api 新增/下架模型或调整分组权限后 5 分钟内下拉框更新；开通会员后分组立即更新
- 预估积分随所选分组倍率变化；选择自定义渠道时不显示预估
- 后台渠道设置中 new-api 渠道在 SSO 模式下只维护 Base URL，不再维护模型列表
- SSO 模式配置弹窗不再显示 本地/远程 切换

## 电商图片工具（P3-B）

- 商品套图：上传 1–6 张 JPG/PNG（≤10MB，或从资产库选择）；SKU 最多 5 个；市场/平台/语言；一键解析卖点得到三类卖点、5 个风格标签与设计规范；AI 优化与换个方向；风格三种模式；智能 9 张或自定义 ≥7 张；SKU 白底图
- 生成预览：未解析/未规划时自动串联“解析 → 规划 → 预览”（缺页自动补规划，最多 3 轮，失败槽位用默认模板并提示）；勾选后生成正式图；按钮显示预估积分
- 同一套图同时只允许一个 AI 辅助任务；在作品/任务里重试电商 AI 辅助（识图）任务会被拒绝，需回套图页重新触发
- SSO 关联用户的电商任务走账号分组渠道（`newapi@`）
- 刷新页面或从历史打开可继续；所有结果出现在“我的作品”的套图/应用分类
- 详情图 / A+ 固定 7 屏竖版
- 图片复刻、去背景（透明/纯白/纯色）、AI 换装（穿戴/场景，可附模特图）
- 后台可配置识图模型、生图模型、预览与正式画质（公开设置 `ecommerce`）

## 模板库与付费模板（P3c 后端）

- 首次启动写入 12 个草稿模板，重启不重复写入；草稿不出现在 `GET /api/templates` 与 `GET /api/templates/:slug`
- 后台 `GET/POST /api/admin/templates`、`PUT/DELETE /api/admin/templates/:id`：标识格式、输入组（≤4 组、每组 1–4 张、合计 ≤6）、比例/分辨率白名单、长度校验
- `POST /api/v1/templates/:slug/generate`：校验图片归属与格式、各组张数、必填提示词（≤2000 字）、比例/分辨率；结果出现在“我的作品”模板分类（`kind=template`，可按 `templateId` 筛选）
- SSO 用户模板任务走账号分组渠道（`newapi@`）；模板费仅在任务成功后收取一次，失败任务不收，会员免费模板与 0 费用模板不收；new-api 扣费失败重试 3 次后记为 `failed`，作品照常交付
- 需与 new-api `POST /api/sso/consume` 联调：消费日志标题为模板名，重复结算同一任务只扣一次

## 图片制作改版（P3c 前端 A）

- `/image` 为图片制作首页：胶囊工具条（含搜索）、精品推荐 6 个工具卡、电商专区 / 创意应用模板卡（来自 `GET /api/templates`，没有已发布模板时不显示该分区）；原自由生图移到 `/image/free`，行为不变
- 工具页统一为"‹ 返回图片创作 + 居中标题"顶栏、左侧 440px 平铺表单（底部吸附主按钮 + 一行提示）、右侧"结果 / 历史 / 示例"面板（有结果时默认"结果"，否则"示例"）；宽度 < 1024px 上下堆叠
- 上传区：点击或拖拽上传、选择文件、从资产库选择，已选图以 72px 缩略图显示并可删除
- 套图 / 详情图：投放设置全宽下拉；"一键解析"、"AI 推荐风格"、"AI 优化"、"换个方向"胶囊按钮显示 ≈积分；套图结构为"智能匹配 / 自定义配置"两张勾选卡与数量步进器；勾选结果后在结果面板底部"生成正式图 · ≈积分"
- 去除背景一次最多 4 张（逐张提交），背景三选一；复刻 / 换装示例为前后对照
- 价格：按次模型 = 单价 × 分组倍率 × 积分比例；按量模型按典型用量估算（解析 3000/1000、规划 6000/3000、优化/换方向 1500/300 tokens），悬停提示"预估值，按实际用量结算"；拿不到价格时不显示
- 示例：后台未配置 `imageExamples` 时显示带编号的渐变占位卡（套图 8 张、详情图 7 屏）；配置后显示上传图片，首页工具卡封面同理
- 浅色 / 深色主题下首页、工具页的配色与对比度

## 模板库前端（P3c 前端 B）

- 模板应用页 `/image/app/[slug]`（首页模板卡进入）：头卡（封面或占位、标题、说明、分类标签，会员免费的付费模板显示"会员免模板费"）；每个输入组一个上传区（各自张数上限，非必填标"可选"）；自定义提示词（必填/选填、占位文案、≤2000 字）；比例与分辨率胶囊只列模板允许的选项
- 底部"本次消耗 ≈x 积分"= 模型预估 × 数量 + 模板费 × 数量（会员且模板会员免费时不含模板费；拿不到模型价格时不显示）；生成数量 1–4；缺必填图片/提示词时按钮禁用并提示缺什么
- 右侧"作品示例"：原图 → AI 作品对照 + 创作提示词与复制；无示例时显示占位。"我的作品"：该模板的历史作品，排队/生成中的任务每 3 秒刷新；提交后自动切到"我的作品"
- 作品详情弹窗（点示例或作品）：大图 + 应用名称 / 参考素材 / 提示词 /"一键同款"（示例只回填提示词；我的作品回填提示词，并按输出尺寸回填最接近的比例与分辨率）；窄屏上下堆叠
- 管理员可预览草稿模板的应用页（标"草稿预览"），但草稿不能生成
- 后台"模板库"：列表（封面、标题/标识、分类与状态筛选、排序、模板费与会员免费、预览/编辑/删除）；编辑表单含输入组（≤4 组、每组 1–4 张、合计 ≤6 张）、系统提示词（`@图片N` 编号预览与 `{{prompt}}` 说明）、比例/分辨率多选、生图模型、模板费、会员免费、状态、排序、封面与示例上传（存储文件地址）；保存前按后端规则校验
